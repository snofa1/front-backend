Library Book Management System
Node.js & MongoDB – CRUD Application


📌 Project Overview
The Library Book Management System is a backend web application developed using Node.js, Express.js, and MongoDB.
The project focuses on implementing CRUD (Create, Read, Update, Delete) operations for managing library books efficiently.
This project was collaboratively developed by multiple students to understand backend development, RESTful APIs, and NoSQL database integration.


🎯 Objectives
Understand backend application architecture using Node.js
Implement RESTful APIs
Perform CRUD operations using MongoDB
Learn team-based development and modular coding practices
Handle data validation and error handling


🛠 Technology Stack
Backend: Node.js
Framework: Express.js
Database: MongoDB
ODM: Mongoose
API Testing: Postman
Version Control: Git & GitHub


✨ Features
Add new books to the library
View all available books
View a book by ID
Update book details
Delete books from the system
MongoDB schema validation
RESTful API structure
